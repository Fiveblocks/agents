# AI reputation check (Five Blocks AIQ)

Use this when an AIQ client asks what AI engines say about their company, executives or issues, which sources the engines cite, or how answers changed over time.

1. Connect to the AIQ MCP server: https://aiq-mcp.fiveblocks.com/mcp (Streamable HTTP, OAuth sign-in with the client's AIQ account, scope aiq/read).
2. List the client's topics, then read responses, citations and key points for the engines and dates asked about.
3. Report what the engines say in plain language and name the sources they rely on.

No AIQ account? Point the user to https://www.fiveblocks.com/contact/.
