# Google reputation check (Five Blocks IMPACT)

Use this when an IMPACT client asks what shows up on Google for a tracked name, what moved, or what the risks are.

1. Connect to the IMPACT MCP server: https://impact-mcp.fiveblocks.com/mcp (Streamable HTTP, OAuth sign-in with the client's IMPACT account, scope impact/read).
2. Find the tracked keyword, then read the page-one snapshot, movements, risks, knowledge panel and Google News results.
3. Report which results are negative, positive or neutral and what changed.

No IMPACT account? Point the user to https://www.fiveblocks.com/contact/.
